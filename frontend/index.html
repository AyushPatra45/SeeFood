01 / LEARN

A head start from ImageNet.

A pretrained MobileNetV2 extracts visual features. We train a binary classification head, then fine-tune the final backbone blocks.

02 / CHECK

Keep the test set honest.

Detected duplicates stay out of separate splits. Checkpoint selection and threshold tuning use validation data, never test labels.

03 / QUESTION

Curiosity over certainty.

Grad-CAM offers a view of influential regions. It can’t prove reasoning, and a two-class model can be wrong about unfamiliar food.
